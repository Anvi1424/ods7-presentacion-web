# ODS 7 Presentacion Web

Presentacion web tipo PowerPoint para GitHub Pages.

## Publicacion

1. Subir todo el contenido de esta carpeta a un repositorio de GitHub.
2. En GitHub: Settings > Pages.
3. En "Build and deployment", seleccionar "Deploy from a branch".
4. Branch: `main`, folder: `/root`.
5. Guardar y abrir el enlace que GitHub Pages genere.

## Notas

- Los videos estan comprimidos para GitHub Pages.
- Los MP4 gigantes 4K locales no se incluyen porque GitHub rechaza archivos de mas de 100 MB.
